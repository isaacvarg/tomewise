# Obsidian and other PKM tools are optional, never required

Nothing depends on a PKM tool. A learning home is plain files that work on their own; vault mode is a choice in `tome init` that scaffolds the learning home into a folder of the learner's choosing inside their vault. Vault mode also writes one Markdown note per session (with a frontmatter summary), a Markdown copy of the curriculum, and Obsidian Base views, so history shows up in the second brain instead of just sitting next to it.

We considered building the app as a plugin for Vaultite (an Obsidian alternative with a plugin system and HTTP API) and rejected it: it would tie every user to one PKM tool.
